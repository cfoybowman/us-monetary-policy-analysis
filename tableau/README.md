# Tableau Dashboard

This folder contains the Tableau visualization component of the U.S. monetary policy analysis project.

## Files

### monetary_policy_impact_dashboard.twbx
Interactive Tableau workbook analyzing inflation, unemployment, and Federal Funds Rate trends across historical and recent economic periods.

### monetary_policy_impact_dashboard.pdf
Static PDF export of the final dashboard for quick portfolio review.

## Dashboard Features

The dashboard includes:

- Current Federal Funds Rate KPI
- Current Inflation YoY KPI
- Current Unemployment KPI
- Average Federal Funds Rate KPI
- Federal Funds Rate trend over time
- Inflation vs. Federal Funds Rate scatter analysis
- Average unemployment by economic period
- Recent inflation and Federal Funds Rate comparison
- Interactive year and economic-period filters

## Analytical Purpose

The Tableau dashboard extends the Python-based monetary policy analysis by providing an interactive business intelligence layer for exploring long-term macroeconomic relationships and recent monetary policy trends.
